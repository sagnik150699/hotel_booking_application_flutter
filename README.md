- Responsive Flutter layout for mobile, tablet, desktop, and web
- Functional hotel search with destination filtering, date selection, and guest controls
- Saved hotel toggles with a saved-list view
- Recommended hotel cards with price, rating, location, and amenities
- Feature-first source organization under `lib/src/features`
- Android package name configured as `com.sagnikbhattacharya.hotelbooking`
- Release APK build support
- GitHub Actions CI for formatting, analysis, tests, and Android debug builds on `main`
